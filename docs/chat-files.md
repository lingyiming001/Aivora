# 聊天文件附件

输入框左下角“＋”可添加图片、文件或生成图片，也支持把文件拖入输入框、粘贴剪贴板图片。附件先显示在待发送区，可查看或移除；点击发送后，角色结合附件内容回答，后续对话保留上下文。

- 每条消息最多4个文档和1张图片，每个文件不超过5MB。
- 支持PDF、Word（.docx）、TXT、Markdown、CSV、JSON、LOG。文本使用UTF-8编码。
- 文件卡片可预览已解析正文、下载原文件。文件只供所属用户和会话读取，原文件不公开托管。
- 单文件最多提取12000字；PDF最多前50页。较长文件显示节选标识，扫描或加密PDF会给出明确提示，暂不进行OCR。
- 模型读取最近最多40条消息，聊天正文与附件参考合计不超过48000字符；文件参考正文另设24000字上限；上传解析文件不调用外部模型，发送按角色原价扣费。
- 文件名、扩展名、大小、PDF格式、Word ZIP/XML边界在服务端校验，文档文本作为参考资料注入上下文，不作为系统指令。
- PDF使用[Apache PDFBox](https://pdfbox.apache.org/) 3.0.8。V21数据库迁移已应用，前后端已重新构建并重启。按用户此前要求未执行功能测试或真实模型调用。

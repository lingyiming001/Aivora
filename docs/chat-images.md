# 聊天图片

- 图片理解：选择PNG/JPEG/WebP图片后，前端压缩转JPEG，服务端使用视觉模型识图，显示待发送图片。填写问题并点击发送；无文字时使用默认看图聊天请求。
- 绘图：输入画面描述，生成后点击“加入聊天”，再填写想聊的内容并发送。发送时由服务端视觉模型识别实际图片，不把绘图提示词当作真实画面。
- 图片保留在聊天消息中，角色通过服务器保存的视觉描述继续对话，使用最近最多40条消息，聊天正文与附件描述总计不超过48000字符。图片预览和描述生成不额外扣用户星币，发送沿用角色价格；供应商自身调用费用保持原规则。
- 聊天预览保比例压缩为最长边512像素的JPEG。V22起新生成/编辑的图片同时保存供应商原图，下载提供原图、编辑优先使用原图；旧记录只有预览时下载JPEG预览。生成结果不依赖短期签名地址继续展示。未发送附件仅属于对应用户与会话；附件引用须服务端校验。
- 供应商错误分为内容审核、额度、鉴权、模型名称/地域、参数、限流等；不向用户暴露供应商原始响应或密钥。日志仅记录模型名、HTTP状态、错误代码和请求标识。
- 接口依据：[千问文生图API](https://help.aliyun.com/zh/model-studio/qwen-image-api)、[视觉理解](https://docs.bailian.console.aliyun.com/zh/model-studio/vision)。绘图跟随模型默认尺寸，避免不同Qwen图像型号的尺寸限制差异。
- V20迁移已自动应用，前后端已重新构建/重启；按用户此前要求未执行真实模型调用或功能测试。先前截图的具体供应商拒绝原因旧日志未保存，需用户手动重试时查看新提示。

## 图片操作

生成结果卡支持放大预览、编辑图片、下载、加入聊天框。编辑时填写修改要求，调用[百炼图像编辑接口](https://help.aliyun.com/en/model-studio/qwen-image-edit-api)基于当前图片生成新结果；支持已配置的Qwen图像2.x/3.x或image-edit型号，其他图像型号会返回不支持编辑提示。编辑不覆盖此前的已发送图片。

原图下载须校验当前用户与所属会话；没有原图的旧图片兼容下载既有预览。新原图经格式、尺寸、字节限制后入库；过大图编辑使用预览回退。V22已迁移并部署，本轮未调用真实模型测试。

# 后台配置与角色卡下架

## 供应商

模型与路由 → 供应商配置显示列表，点击“新增供应商”或“编辑配置”打开表单。新供应商默认停用，可先保存配置；启用需要 API Key。编辑密钥留空保留原值，移除密钥会停用供应商。供应商名称唯一，新增后在模型列表添加相应模型。当前新增接入协议为 OpenAI 兼容 API；原有模型调用与组合路由限制保持不变。

## 菜单权限

超级管理员可新增、修改、删除菜单目录，编辑名称、分组、排序与说明。权限标识创建后不可修改。目录同步到后台导航和角色授权列表；删除菜单会同时撤销关联角色的该项权限，业务数据保留。

管理员管理、角色管理、菜单权限三个系统入口不能删除，也不能授予普通业务角色。自定义菜单注册后显示待接入页面，业务页面和对应 API 需要单独实现。

## 角色卡下架

持有“角色卡管理”权限的运营管理员可下架已发布角色，必须填写原因。下架后角色移出广场，服务端阻止新的文字/媒体请求，历史聊天记录保留；已经开始的请求不会强制中断。

作者在“我的角色”和“消息”中查看原因，可修改后重新投稿审核，审核通过才重新发布。后台保留下架原因、时间、操作者和操作日志。

## 我的账号与管理员账号

后台右上角头像菜单提供个人资料、修改密码、手机绑定/换绑。资料可修改头像、昵称和简介；登录邮箱保持只读。普通管理员即使尚未分配业务菜单，也可通过 `/admin/account` 管理个人账号。

密码修改须校验当前密码，新密码为8至64位字母数字组合，BCrypt输入不超过72字节。当前密码连续验证失败5次后冷却15分钟。修改密码会撤销全部登录会话，需重新登录。

首次绑定手机验证当前密码及新手机验证码；换绑同时验证原手机和新手机验证码。验证码按用户、手机、OLD/NEW用途、会话版本隔离，有效5分钟、最多5次尝试、60秒重发、每用户/IP每小时20次。成功绑定或换绑后撤销旧会话并重新登录。现有短信实现只在dev环境返回明确标记的开发验证码，尚未接真实短信网关；生产环境不会模拟成功发送短信。

仅超级管理员可在“管理员管理”直接创建新管理员，输入邮箱、昵称、初始密码、启停状态并分配业务角色。新账号不会获得超级管理员资格。也保留把现有普通用户设为管理员的入口。

启停和强制下线仅针对其他非超级管理员账号。停用禁止登录；强制下线撤销所有设备的刷新令牌并递增服务端会话版本，已签发JWT在后续请求中失效；管理员页面约30秒同步会话状态，也会在接口401时清理相应管理员登录状态。下线不禁止重新登录，停用需先重新启用。正在执行的请求不会被强行中断。

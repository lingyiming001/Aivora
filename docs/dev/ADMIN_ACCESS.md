# 管理员、角色与权限（V12）

2026-10-14。AI 角色卡与管理员权限角色分开。

## 后台结构
- 平台运营：运营概览、用户管理、角色卡管理、模型与路由。
- 财务管理：充值订单、钱包流水、异常对账。
- 系统管理：管理员管理、角色管理、菜单权限、操作日志、系统状态。

## 标准角色授权
超级管理员保留全部权限。业务管理员关联一个或多个角色，权限取所有启用角色的并集。
角色支持编码、名称、说明、启停、菜单授权、删除；已分配角色不可删除，需先移除关联。
预置内容审核员与运营人员。原按个人保存的权限迁移为历史角色，避免升级丢失权限。
管理员页面分配角色，不再直接勾选个人菜单；停用角色或撤销关联后接口立即拒绝旧会话的访问。
管理员管理、角色管理、菜单权限三个授权管理入口仅超级管理员访问，防止业务管理员扩大权限。
菜单目录按平台/财务/系统分组，与页面和接口绑定；授权粒度为菜单业务读写，尚非按钮级权限。

## 角色卡管理
列表可搜索与筛选状态；投稿审核展示投稿人、设定、开场白，支持通过发布和填写原因驳回；价格设置独立页签。
驳回退回私密草稿，原因在客户端显示，用户可修改再提交。

## 验证
隔离API验证角色创建、管理员分配、越权403、角色停用即时撤权、在用角色删除保护、超级管理员授权边界。
浏览器核验角色表格、角色卡列表/审核/价格页签、分组导航。

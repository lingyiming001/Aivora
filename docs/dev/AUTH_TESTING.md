# 登录与角色卡测试

用户入口 `/login`，管理员入口 `/admin/login`。两端均支持“账号密码”和“手机验证码”；登录成功后的令牌、跳转和权限继续分离。

## 本地体验
- 当前为 `dev` 模式。用户测试手机号：`19900000001`，首次创建时赠送 200 测试星币；管理员测试手机号：`19900000000`，仅绑定本机首个尚未绑定手机号的有效管理员。
- 选择手机验证码，填写手机号，点击“获取验证码”。页面明确显示开发模式和本次测试码，可点击“填入验证码”。不会发送真实短信。
- 账号密码支持用户名、邮箱或已绑定手机号；原管理员邮箱/密码不变。用户可通过“创建账号”设置用户名、昵称和密码。体验手机号账号未设置可公开使用的密码，请使用验证码登录。
- 验证码 5 分钟有效、60 秒发送间隔、每个来源 IP 每小时最多 20 次，错误验证最多 5 次且成功后不可重复使用。两端验证码独立，普通用户不能获得管理员权限。
- 未注册的用户手机号验证成功后创建普通用户，初始余额为零；管理员手机号必须已绑定，不开放自动管理员注册。

## 正式环境边界
- 验证码发送与验证均在非 dev 模式关闭，返回 SMS_NOT_CONFIGURED；没有固定万能验证码，也不会返回开发验证码。
- 正式短信供应商尚未接入。开发测试手机号不能作为生产管理员手机号；生产应使用独立数据库和真实绑定流程。

# 模型与路由

管理员登录 `/admin/login` 后进入 `/admin/models`。

1. 找到供应商，填写 API Key，点击“保存并启用”。预置模型默认开启，只有供应商同时启用才可参与服务端路由。
2. 如果尚无默认路由，自动选中该供应商的首个启用模型。也可以在“模型列表与路由 → 编辑”中指定默认模型，调整模型参考费用；用户实际扣费以角色卡价格为准。
3. 模型 ID 支持手动添加，须使用供应商实际提供的名称。Base URL 可按地域修改；百炼支持工作空间专属域名，Kimi 区分中国与国际站账号。
4. 连接测试会发送一条最多 16 输出 token 的短消息，可能产生少量供应商费用；超时为 20 秒。成功表示该模型接口返回兼容响应，实际长对话仍受额度、权限与网络影响。
5. 密钥字段为空会保留原值；移除密钥会停用供应商。密钥以现有 AES-GCM 主密钥加密保存，API 不返回原文或密文。服务器必须设置 `PROVIDER_ENCRYPTION_KEY`。
6. 每次发送均由服务端按用户等级与角色当前价格选择路由，客户端不能指定模型；无匹配规则使用启用的兜底模型，无可用模型在扣费前拦截。

预置 7 家供应商、13 个文字模型；数据库中已有演示供应商与模型继续保留。迁移 V4 添加预置数据和角色分类，V5 为已有启用模型初始化默认路由。预置导入不覆盖现有密钥和启用状态。

## V10 模型类型与组合草稿（2026-10-14）
- 模型新增 TEXT（文字）、CHAT（聊天）、VOICE（语音），现有模型默认 CHAT；模型页可筛选并编辑类型。
- 文字/聊天均要求现有 Chat Completions 兼容接口，VOICE 仅登记，不能设为文字聊天兜底或参与文字路由，不能执行文字连接测试。
- 已被路由引用的模型不能直接改为 VOICE；包含同名模型 upsert 的校验。
- 组合方案可配置主模型与最多 3 个不同辅助模型、消息长度门槛；只允许保存停用草稿。
- 实际多模型执行尚未实现，自动审批以聊天数据涉及多供应商传输、尚未指定获准供应商为由拒绝；已通过异步问题请求用户确认供应商。没有绕过拒绝，也未执行外部调用。

## 阿里云百炼组合流程已接入（2026-10-14）
用户明确授权“阿里云百炼”，原实际组合执行阻塞已解除。前述V10停用草稿限制已移除；不扩大到其他供应商。

1. 后台“模型与路由 → 自动路由规则”创建或编辑规则，设用户等级/角色价格区间。
2. 主回复模型选择百炼模型（例如已有qwen-plus），勾选最多3个不同辅助文字/聊天模型，设置消息长度门槛；0为每条启用组合。
3. 设置优先级并启用。达到门槛后辅助模型并行生成建议（总等待40秒），主模型汇总并流式回复（最多120秒）；门槛以下只使用主模型。
4. 组合调用在保存启用规则和运行时校验 HTTPS、官方主机 dashscope.aliyuncs.com、默认或443端口。不能使用其他供应商、仿冒主机或携带URL凭据；供应商Base URL修改后运行时会重新校验。
5. 辅助结果仅提供给主模型，不直接发给客户端；每个结果限4000字符，汇总时标记为不可信参考。
6. 每条按角色价格预扣一次；任一步失败沿用请求结算服务退款。请求composition_model_ids记录本次实际使用的辅助模型；低于门槛为空。
